# coffee-sales-analysis
☕ Cafe Sales Analytics with Excel

این پروژه با هدف پاک‌سازی، تحلیل و بصری‌سازی داده‌های فروش یک کافه در Microsoft Excel انجام شده است.

هدف اصلی، تبدیل داده‌های خام و نامنظم به اطلاعات قابل تحلیل و ساخت یک Interactive Dashboard برای بررسی عملکرد فروش است.
📌 مراحل پروژه :
1. Data Cleaning

داده‌های خام شامل مقادیر ناقص، ERROR و UNKNOWN بودند.

در بخش داده های پاک سازی شده:

داده‌های نامعتبر و ناقص بررسی و اصلاح شدند.

مقادیر دسته‌بندی‌شده استاندارد شدند.

ستون‌های موردنیاز برای تحلیل ایجاد شدند.

داده‌ها در قالب Excel Table سازمان‌دهی شدند.

2. Data Analysis

در بخش تجزیه و تحلیل شاخص‌های اصلی فروش بررسی شدند:

میزان فروش محصولات

درآمد ماهانه

تعداد فروش

روش‌های پرداخت

بیشترین و کمترین مقدار فروش

برای محاسبات از توابع زیر استفاده شده است:

SUMIF SUMIFS INDEX MATCH IF MAX MIN

3. Interactive Dashboard

در شیت نمودار ها نتایج تحلیل‌ها به صورت نمودارهای قابل فهم نمایش داده شده‌اند.

یکی از بخش‌های اصلی پروژه Interactive Product Selection است.

با استفاده از Data Validation Dropdown کاربر می‌تواند محصول موردنظر خود را انتخاب کند؛ مانند:

Sandwich | Tea | Coffee | Cake

با تغییر محصول، اطلاعات و نمودارهای مرتبط نیز به صورت پویا تغییر می‌کنند.
